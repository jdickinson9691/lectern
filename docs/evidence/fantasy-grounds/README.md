# Fantasy Grounds Evidence

Store sanitized Fantasy Grounds evidence here when it is small, lawful, and
required for a contract or regression.

Each evidence package should identify:

- related contract ID;
- Lectern Sync version;
- Fantasy Grounds version and ruleset;
- snapshot contract version;
- encounter name and sanitized sequence range;
- authoritative observation;
- known gaps or ambiguity;
- corresponding automated fixture, when one exists.

Do not store live campaign folders or complete module-derived records.
