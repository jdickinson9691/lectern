# Acceptance Evidence

Store durable manual-test matrices and release-verification summaries here.

Each record should include:

- scope and related contract or milestone;
- application, schema, extension, and narrative-library versions;
- test date and environment;
- pass, fail, blocked, or deferred result;
- links to sanitized fixtures or screenshots;
- unresolved risks and required follow-up.

Generated logs and build output belong outside version control.
