# Ashen Company class and subclass access

The earlier campaign architecture gave this **example** access list. It is the working character-creation plan until the GM confirms it at session zero and records the decision in canon. Official 2024 class rules stay unchanged.

| Option | Working access |
|---|---|
| Fighter / Champion | Starting |
| Rogue / Thief | Starting |
| Bard / College of Lore | Starting |
| Sorcerer / Draconic Sorcery | Starting |
| Wizard | Restricted |
| Warlock | Restricted |
| Paladin | Restricted |
| Ranger | Locked |

Starting options can be selected when character creation opens. Restricted options require a specific story permission or GM exception. Locked options require an in-game unlock. Other classes and subclasses remain unclassified; the GM must review them before use.

Lectern currently stores class and subclass names on character rows but does not enforce this access list. The GM maintains a dated manual decision log until campaign option records and validation exist. The player-facing copy is in [Ashen Company Player Guide](Ashen_Company_Player_Guide.docx).
