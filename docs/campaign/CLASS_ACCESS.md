# Ashen Company class and subclass access

The GM has decided that Cleric, Paladin, Wizard, and Warlock are unavailable to new Ashen Company characters because their traditions ended after the Sundering. This is a campaign access rule; official 2024 class rules stay unchanged. The world-creation account is still a GM review draft and has not been approved as canon.

| Option | Working access |
|---|---|
| Fighter / Champion | Starting |
| Rogue / Thief | Starting |
| Bard / College of Lore | Starting |
| Sorcerer / Draconic Sorcery | Starting |
| Cleric | Unavailable to new characters |
| Wizard | Unavailable to new characters |
| Warlock | Unavailable to new characters |
| Paladin | Unavailable to new characters |
| Ranger | Locked |

Starting options can be selected when character creation opens. The four unavailable classes cannot be selected for new characters. Locked options require an in-game unlock. Other classes and subclasses remain unclassified; the GM must review them before use.

Lectern currently stores class and subclass names on character rows but does not enforce this access list. The GM maintains a dated manual decision log until campaign option records and validation exist. The player-facing copy is in [Ashen Company Player Guide](Ashen_Company_Player_Guide.docx).
