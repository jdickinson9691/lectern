# Completed Agent Contracts

- every acceptance criterion has a recorded result;
- required automated verification passes;
- authorized manual or live checks are recorded;
- remaining risks are explicit;
- the PRD and changelog are updated when required;
- commit and artifact identifiers are recorded when those actions were authorized.

Do not rewrite a completed contract to describe later work. Create a new contract
that links back to the completed one.
